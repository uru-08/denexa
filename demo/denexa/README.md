# DENEXA Demo editable

Esta carpeta es la base del demo que vamos a ir editando.

## Archivos principales

- `index.html`: estructura visual del menú.
- `styles.css`: colores, tamaños, botones, grillas y diseño.
- `data.js`: categorías, productos, precios e imágenes.
- `app.js`: funcionamiento del carrito, botones y navegación.
- `assets/denexa-logo.png`: logo de DENEXA aportado por el usuario.

## Para probarlo

Abrir `index.html` en Chrome.
